# models/

3D models (.glb/.gltf) render REAL here: full textures. Parted models can EXPLODE.

## Included sample models

Sourced from Khronos Group's [glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
(the official glTF test/demo model set) so `summon_model` has something
real to work with out of the box. Every file's license was checked
individually before including it — see each model's `metadata.json`/
`LICENSE.md` in that repo for the authoritative source.

| File | License | Credit |
|---|---|---|
| `DamagedHelmet.glb` | CC-BY-4.0 | theblueturtle_ |
| `ToyCar.glb` | CC0-1.0 (public domain) | Guido Odendahl, Eric Chadwick |
| `BoomBox.glb` | CC0-1.0 (public domain) | Microsoft |

`DamagedHelmet.glb` is also symlinked into `../holo/` for the wireframe
hologram look — same file, not a second download.
